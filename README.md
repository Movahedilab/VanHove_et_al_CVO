# VanHove_et_al_CVO

This repository contains the code, used for analyzing the scRNAseq data of Van Hove et al. (Microglia with distinct origins and non-canonical phenotypes coexist within the border-like niche of the brain’s circumventricular organs, Immunity, 2026)

### Code
Single_cell_datasets.Rmd - code for reproducing the figures in the publication
